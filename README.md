# Hiraeth
Hiraeth is a 2D platformer made with Unity 6 inspired by the platformer Celeste. Hiraeth combines moving, jumping, dashing, wall grabbing, and wall climbing to create a unique set of movements that the user is able to interact with.

- C#
- Unity6
- Aseprite
- C++ for rendering pipeline
